# 板块低位后短期启动回测

数据更新至：2026-10-09

## 统一口径

- 数据：中证与国证官方指数日线；未使用同花顺。
- 候选：拥挤度首次进入0-20区间，随后最多等待10个交易日确认启动。
- 去重：同一方案的实际确认信号至少间隔10个交易日。
- 统计：以确认日收盘为基准，观察之后1/3/5/10日，不把信号当天涨幅算入结果。
- 启动：未来1/3/5/10日内最高收盘分别达到+2%/+3%/+5%/+8%。
- 用途：衡量日线信号的后续启动概率，不等同于可成交的盘中策略收益。

## 当前判读

- CPO（中证光通信）：低位相对普通时期的3日启动率变化+0.9个百分点，5日变化+10.5个百分点；可继续验证：单日相对大盘转强（3日超额中位数0.3%）。
- PCB（国证PCB）：低位相对普通时期的3日启动率变化-8.3个百分点，5日变化-6.1个百分点；暂无可靠的3日确认条件。
- 化工（中证细分化工）：低位相对普通时期的3日启动率变化+2.2个百分点，5日变化+3.9个百分点；可继续验证：单日相对大盘转强（3日超额中位数0.6%）、3日相对大盘转强（3日超额中位数1.1%）、突破与相对强度组合（3日超额中位数0.2%）。
- 有色铜代理（中证工业有色）：低位相对普通时期的3日启动率变化+14.6个百分点，5日变化+2.7个百分点；暂无可靠的3日确认条件。

## 判断限制

- 只有四个板块，无法可靠计算全市场前20%涨速或上涨家数，这两项需要更完整的板块池和分钟数据。
- 日线只能验证低位后是否较快启动，无法证明盘中哪个时刻适合买入。
- 各方案共享大量相同市场阶段，结果不能视为完全独立样本。
- 化工和有色仍需商品价格、库存或价差等周期变量；价格确认只能作为辅助。
